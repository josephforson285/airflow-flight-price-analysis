# dbt lives in its OWN virtualenv inside the image, never in Airflow's
# environment. Measured against apache/airflow:3.3.1, installing dbt-core
# alongside Airflow downgrades two packages Airflow already pins:
#
#     more-itertools  11.1.0 -> 10.8.0
#     pathspec         1.1.1 ->  1.0.4
#
# Neither is obviously fatal, which is exactly what makes it dangerous: the
# breakage would surface later, somewhere unrelated, and look like a bug in
# our code. An isolated venv costs a few lines and removes the question.
#
# Cosmos itself installs into the Airflow env with zero version changes, so
# only dbt needs the isolation.
dbt-core
dbt-postgres
